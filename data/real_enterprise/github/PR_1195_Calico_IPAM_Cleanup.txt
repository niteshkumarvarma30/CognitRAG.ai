GitHub Pull Request #1195: Configure auto-release of unallocated IPAM blocks in Calico CNI
Repo: platform / kubernetes-deployments
Author: Maya Lin (@mayalin)
Reviewers: Carlos Santos (@csantos)
Status: Merged (Commit: e331401)
Related Issues: Resolves K8S-11942

Overview:
Configures Calico CNI daemonset to automatically reclaim vacated IP address blocks upon rapid pod downscaling in `payment-gateway` and batch namespaces.

Manifest Diff:
```yaml
# deploy/cni/calico-config.yaml
  apiVersion: crd.projectcalico.org/v1
  kind: IPPool
  metadata:
    name: default-ipv4-ippool
  spec:
+   blockSize: 26
+   nodeSelector: all()
+   vxlanMode: Always
+   strictAffinity: false
+   autoReleaseUnusedPerNodeBlocks: true
```

Impact:
IP allocation exhaustion eliminated during 20 -> 180 -> 20 pod autoscaling spikes. IP reclamation completes in < 5 minutes.
