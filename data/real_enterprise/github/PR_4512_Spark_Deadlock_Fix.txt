GitHub Pull Request #4512: Fix TaskSchedulerImpl synchronized lock inversion on stage cancellation
Repo: internal-engine / spark-fork
Author: Chen Wei (@chenwei)
Reviewers: Liam Zhao (@liamzhao), Priya Patel (@ppatel)
Status: Merged (Commit: 8f2c9e1)
Related Issues: Resolves SPARK-45120

Overview:
Eliminates deadlock condition occurring when DAGScheduler cancels a running stage during simultaneous Kubernetes executor loss. Decouples stage abort notifications from TaskSchedulerImpl lock.

Code Changes:
```scala
// core/src/main/scala/org/apache/spark/scheduler/TaskSchedulerImpl.scala
- synchronized {
-   val manager = stageIdToTaskSetManager.get(stageId)
-   if (manager != null) manager.abortStage(reason)
- }
+ val manager = activeTaskSetManagers.get(stageId)
+ if (manager != null) {
+   manager.abortStageAsync(reason)
+ }
```

Testing & Validation:
Executed `StressTestExecutorLossSuite` with 10,000 parallel stage cancel events across 64 mock worker threads. All 10,000 cancellations completed without lock contention or thread stalls.
