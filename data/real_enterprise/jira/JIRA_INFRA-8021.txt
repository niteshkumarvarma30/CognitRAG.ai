Title: Enforce automatic annual key rotation on all customer-managed KMS keys

Description:
SOC 2 Type II audit finding SEC-2024-03 requires that all customer-managed KMS encryption keys (used for Supabase Postgres storage, S3 backups, and EBS root volumes) have automatic rotation enabled.

Several legacy Terraform modules in `infra-live-us-east-1` created `aws_kms_key` without setting `enable_key_rotation = true`.

Resolution:
Resolved in GitHub PR #8022. Updated Terraform KMS module across all accounts (dev, staging, prod) to set `enable_key_rotation = true`. Verified AWS CloudTrail logs confirm `KMS:EnableKeyRotation` succeeded for all 24 production keys with zero service downtime.
