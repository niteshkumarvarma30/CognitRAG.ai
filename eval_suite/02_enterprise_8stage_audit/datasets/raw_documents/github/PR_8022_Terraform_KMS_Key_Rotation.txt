Author: Marcus Vance (@marcusv)
Reviewers: Jessica Wong (@jwong)

Related Issues: Resolves INFRA-8021

Overview:
Sets `enable_key_rotation = true` on the root KMS Terraform resource module, remediating SOC 2 finding SEC-2024-03.

Terraform Diff:
```hcl
# modules/security/kms/main.tf
resource "aws_kms_key" "primary" {
  description             = var.key_description
  deletion_window_in_days = 30
+ enable_key_rotation     = true
  tags                    = local.common_tags
}
```

Verification:
Applied via GitHub Actions CI/CD to production. AWS CLI `aws kms get-key-rotation-status` returned `KeyRotationEnabled: true` for all 24 customer-managed keys.
