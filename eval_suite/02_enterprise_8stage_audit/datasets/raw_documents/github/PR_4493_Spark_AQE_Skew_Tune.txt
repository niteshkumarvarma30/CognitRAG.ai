GitHub Pull Request #4493: Tune AQE skewed partition threshold and dynamic splitting
Repo: internal-engine / spark-fork
Author: Elena Rostova (@elena-r)
Reviewers: Priya Patel (@ppatel), Chen Wei (@chenwei)
Status: Merged (Commit: 4a7b21d)
Related Issues: Resolves SPARK-44912

Overview:
Lowers `spark.sql.adaptive.skewJoin.skewedPartitionFactor` from 5.0 to 2.5 and enforces 256MB threshold to split high-skew partitions in multi-tenant reporting joins.

Configuration Changes in `conf/spark-defaults.conf`:
```properties
+ spark.sql.adaptive.skewJoin.enabled = true
+ spark.sql.adaptive.skewJoin.skewedPartitionFactor = 2.5
+ spark.sql.adaptive.skewJoin.skewedPartitionThresholdInBytes = 268435456
+ spark.sql.adaptive.advisoryPartitionSizeInBytes = 134217728
```

Results:
Benchmarked against 450GB daily analytics join. Partition runtime variance dropped by 86%. Maximum task duration dropped from 42m to 228s.
