Title: Rotate expiring SAML signing certificates in Keycloak production realm

Description:
The X.509 signing and encryption certificate for the enterprise SAML Identity Provider (Okta / Azure AD federation) is scheduled to expire on November 15, 2024. Without rotation, enterprise SSO logins will fail with `SAML2SignatureValidationException`.

Resolution:
Resolved in GitHub PR #4015. 
1) Generated new 4096-bit RSA certificate and private key in AWS KMS.
2) Configured dual-key rollover in Keycloak realm `enterprise-corp`: added new certificate as secondary signing key.
3) Distributed updated SAML metadata XML to enterprise customers.
4) Swapped primary key after 7-day grace period. Zero user authentication disruption observed.
