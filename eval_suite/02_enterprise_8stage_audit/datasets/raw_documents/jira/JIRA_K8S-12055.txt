Title: Kubelet PLEG (Pod Lifecycle Event Generator) timeout causing node NotReady flap

Description:
Worker nodes hosting large numbers of short-lived batch jobs experience PLEG timeouts: `PLEG is not healthy: pleg was last seen active 3m12s ago; threshold is 3m0s`. Kube-controller-manager marks the node as `NotReady` and begins evicting pods.

Analysis:
The `containerd` CRI status query executes synchronous `stat` calls on overlayfs directories. When container volumes contain millions of temporary scratch files, `ListPodSandbox` blocks for >180s.

Resolution:
Resolved in GitHub PR #1206. Upgraded containerd to 1.7.13 which introduces asynchronous sandbox status caching. Configured Kubelet flag `--housekeeping-interval=15s` and enabled systemd cgroup v2 memory pressure alarms.
