Title: Ingress-nginx controller worker OOMKilled under high HTTP/2 multiplexing

Description:
Ingress-nginx pods in production ingress namespace crash with `Exit Code 137 (OOMKilled)`. Memory spikes from 800MB baseline to 4GiB limit within 15 minutes of peak traffic.

Inspection showed that external mobile clients holding persistent HTTP/2 connections send bursty payloads, causing nginx upstream buffer allocations (`proxy_buffers` and `proxy_buffer_size`) to leak per-connection memory.

Resolution:
Resolved in GitHub PR #1181. Optimized ingress-nginx ConfigMap:
1) `proxy-buffer-size: "16k"`
2) `proxy-buffers-number: "4"`
3) `http2-max-field-size: "16k"`
4) Set `client-header-buffer-size: "8k"`. Memory consumption stabilized under 1.2GiB at 45k requests/sec.
